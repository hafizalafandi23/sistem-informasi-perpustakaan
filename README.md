# 📚 Sistem Informasi Perpustakaan Berbasis Web

Repository ini berisi proyek **Sistem Informasi Perpustakaan Berbasis Web** yang dibuat untuk memenuhi tugas Mata Kuliah **Rancangan Perangkat Lunak (RPL)**.

---

## 📖 Deskripsi

Sistem Informasi Perpustakaan Berbasis Web adalah aplikasi yang dirancang untuk mempermudah pengelolaan data buku, anggota, serta proses peminjaman dan pengembalian buku secara digital. Aplikasi ini memiliki dua jenis pengguna utama, yaitu **Admin (Petugas Perpustakaan)** dan **Anggota (Siswa/Mahasiswa)**.

---

## ✨ Fitur Utama

### 🔐 Fitur Admin
- Login sebagai Admin
- Kelola Data Buku (Tambah, Edit, Hapus)
- Kelola Data Anggota
- Kelola Transaksi Peminjaman Buku
- Kelola Transaksi Pengembalian Buku
- Cetak Laporan Peminjaman

### 👤 Fitur Anggota
- Login sebagai Anggota
- Melihat Katalog Buku
- Mencari Buku (Berdasarkan Judul, Penulis, Kategori)
- Melihat Riwayat Peminjaman
- Melihat Status Buku (Dipinjam / Tersedia)

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Struktur halaman web
- **CSS3** — Tampilan dan desain antarmuka
- **JavaScript** — Logika dan interaksi pengguna
